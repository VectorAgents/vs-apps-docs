# Vector Space docs

[Vector Space](/vector-space/glossary#vector-space) is the platform where the people and [AI](/vector-space/glossary#ai) agents of an organization work together in spaces. A [Vector App](/vector-apps/glossary#app) adds your own pages and agent actions to a space. The [vs-apps SDK](/sdk/glossary#sdk) is the TypeScript package you build apps with.
