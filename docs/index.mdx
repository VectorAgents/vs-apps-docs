# Build apps for Vector Space

A Vector app is a TypeScript package with a React client and a Node server that runs in a [space](/vector-space/glossary#space) of [Vector Space](/vector-space/glossary#vector-space). One [app definition](/sdk/glossary#app-definition) lists the [app pages](/vector-apps/glossary#app-page) and [capabilities](/vector-apps/glossary#capability) of your app. Vector Space shows an app page only to users who hold the page's capability.

<Link className="button button--primary button--lg landing-start" to="/vector-apps/quickstart">Start Quickstart</Link>

```ts title="shared/src/index.ts"
import { defineApp } from '@vectoragents/vs-apps';

export const definition = defineApp({
  key: 'hello-app',
  version: '0.1.0',
  pages: [{ key: 'home', label: 'Home', path: '/', capability: 'hello:view' }],
  capabilities: [{ key: 'hello:view', label: 'View hello', effect: 'read' }],
});
```
